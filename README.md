# SmartCrop Vision 🌱

An AI-powered multi-crop plant disease detection system using computer vision and deep learning.

## Project Goal

SmartCrop Vision allows a user to upload an image of a plant leaf and predicts the corresponding plant disease using a deep learning model.

## Pipeline

Image Upload
→ Preprocessing
→ Deep Learning Model
→ Disease Prediction
→ Confidence Score

## Planned Features

- Multi-crop disease classification
- Image preprocessing
- Transfer learning
- Model evaluation
- FastAPI prediction API
- User image upload
- Prediction confidence
- Disease information

## Tech Stack

- Python
- TensorFlow
- OpenCV
- NumPy
- Pandas
- FastAPI
- Git/GitHub

PlantVillage Dataset
